Отчёт по проекту StringDetective
Автор: Парфёнова Арина

1. Исходный код и найденные ошибки

Файл стартового кода от преподавателя не предоставлялся. Поэтому для практики была создана собственная начальная версия программы с пятью намеренно добавленными ошибками. В отчёте это отмечено, чтобы не представлять созданный код как исходный код преподавателя.

1) GetWordCount разделял текст только по обычному пробелу и учитывал пустые части строки. Исправлено: пустой текст возвращает 0, разделителями служат пробелы, табуляция и переносы строк, пустые элементы пропускаются.
2) GetMostFrequentWord сортировал слова по возрастанию числа повторений и мог возвращать наименее частое слово. Исправлено: частоты сортируются по убыванию.
3) RemovePunctuation удалял только точку, запятую, восклицательный и вопросительный знаки. Исправлено: удаляются символы Unicode категории пунктуации.
4) GetTopWords разделял текст только по обычному пробелу и неправильно обрабатывал табуляцию и переносы строк. Исправлено: используются все основные пробельные символы, пустые элементы пропускаются.
5) GetTopWords сортировал частоты по возрастанию, поэтому в начало попадали редкие слова. Исправлено: частые слова выводятся первыми; при равной частоте применяется алфавитная сортировка.

2. Использованные команды Git

Инициализация и сохранение проекта:
git init
git add .
git commit -m "осмысленное сообщение"

Проверка состояния и истории:
git status
git log --oneline --graph

Добавление исправленного файла и отдельный коммит:
git add Program.cs
git commit -m "Исправлено ..."

Файлы сборки исключены с помощью .gitignore (bin/ и obj/). Папка .git включена в архив, чтобы сохранить историю коммитов.

Ответ на вопрос о git commit -am: команда подходит для уже отслеживаемых файлов; новые файлы сначала нужно добавить через git add.

3. Реализованные методы

GetWordCount считает слова, разделённые пробельными символами, и возвращает 0 для пустого текста.
GetMostFrequentWord игнорирует регистр, удаляет пунктуацию и возвращает слово с наибольшей частотой.
RemovePunctuation удаляет знаки пунктуации Unicode.
GetTopWords (бонус) возвращает указанное количество самых частых слов по убыванию частоты.

4. Финальная программа

Консольное меню позволяет подсчитать слова, найти самое частое слово, удалить знаки пунктуации, показать топ-5 слов, ввести новый текст и выйти из программы. Неизвестный пункт меню обрабатывается сообщением.

Примечание: число коммитов и их сообщения можно проверить командой git log --oneline.
